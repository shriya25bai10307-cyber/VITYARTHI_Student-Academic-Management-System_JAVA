# Project Statement

## Project Title
Smart Student Academic Management System

## Problem Statement
Managing student academic information manually can be time-consuming and difficult to organize. Student details, marks, attendance, grades and performance records may be stored separately.

This project provides a centralized web-based system to manage student information and academic performance efficiently.

## Scope
- Student information management
- Academic record management
- Marks and attendance management
- Grade and GPA calculation
- Performance analysis
- Student report generation

## Target Users
- Students
- Faculty members
- Academic administrators

## High-Level Features
1. Student Management
2. Academic Management
3. Performance Analytics
4. Student Reports
5. Data Validation
6. Persistent Data Storage

## Technologies Used
- Java
- Spring Boot
- Spring MVC
- Thymeleaf
- HTML
- CSS
- Maven

## Expected Outcome
The system provides an organized platform for managing student academic information and automatically calculating grades, average marks, GPA and performance status.
