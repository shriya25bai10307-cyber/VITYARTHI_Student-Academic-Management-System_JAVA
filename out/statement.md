# Project Statement

## Project Title
Smart Student Academic Management System

## Problem Statement
Managing student academic information manually can be time-consuming
and may lead to errors in maintaining student details, marks, attendance,
and performance records.

## Project Scope
The project provides a Java-based system to manage student information
and academic records. It supports student management, academic record
management, performance analysis, attendance monitoring, and report
generation.

## Target Users
- Students
- Faculty members
- Academic coordinators

## High-Level Features
- Add, search, update, and delete student records
- Add academic records for subjects
- Calculate grades, grade points, average marks, and GPA
- Identify weak subjects
- Generate attendance warnings
- Generate student academic reports
- Save and load data using file handling
- Validate user input and handle invalid data
